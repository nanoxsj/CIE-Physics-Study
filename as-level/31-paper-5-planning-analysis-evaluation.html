Paper 5 Planning, Analysis and Evaluation / 实验设计与数据分析

Complete examination framework / 完整考点框架 · Cambridge International AS & A Level Physics 9702

使用说明 / How to use this chapter

Paper 5 是书面形式的 Planning, Analysis and Evaluation。它不要求在考试现场操作 laboratory apparatus，但要求考生能够像做真实实验一样设计方法、处理 data、估计 uncertainty 和评价 evidence。

本章根据：

  • current syllabus 的 Paper 5 requirements；
  • available 2020–2023 和 2025 Paper 5 Question Papers / Mark Schemes；
  • Cambridge 9702 常用的 practical terminology；
  • 自拟 worked examples，不冒充真题。

核心原则 / Core principle

Paper 5 tests whether an experiment is workable, measurable and analyzable. 不是写出“看起来科学”的方案，而是要说明 apparatus 如何摆放、每个 quantity 如何测量、哪些 variables 保持 constant、data 如何转换成 graph，以及如何由 graph 得到 physical constant。

1. Examination structure / 考试结构

Feature Requirement
Component Paper 5 Planning, Analysis and Evaluation
Duration 1 hour 15 minutes
Total marks 30 marks
Questions Two compulsory questions, normally 15 marks each
Question 1 Planning an experimental investigation
Question 2 Analysis, conclusions and evaluation of supplied data
Laboratory No laboratory facilities are required
Context May include physics outside the familiar classroom experiments；necessary information will be provided

Question 1：Planning

Question 1 normally asks you to design an experiment to test a suggested relationship. The answer should normally include：

  1. the independent variable；
  2. the dependent variable；
  3. the control variables；
  4. a labelled and workable apparatus diagram；
  5. a method for changing and measuring variables；
  6. a method for collecting enough data；
  7. a method of analysis；
  8. relevant additional details and safety precautions。

Question 2：Analysis, conclusions and evaluation

Question 2 normally provides an equation and experimental data. You may need to：

  1. rearrange or interpret the equation；
  2. calculate derived quantities；
  3. calculate logarithms or reciprocal quantities；
  4. complete a table；
  5. plot data and error bars；
  6. draw a line of best fit and a worst acceptable line；
  7. determine gradient and y-intercept；
  8. determine uncertainties in gradient、intercept and constants；
  9. draw a conclusion or make a prediction。

3. Question 1 Planning / 实验设计题

3.1 Define the problem / 定义问题

首先把题目中的 relationship 转换成 variables：

  • independent variable：你主动改变的 quantity；
  • dependent variable：随 independent variable 改变而测量的 quantity；
  • control variables：必须保持 constant 的 quantities。

Example / 示例：spring experiment

若要研究 spring constant \(k\) 如何随 wire diameter \(d\) 改变：

  • independent variable：\(d\) 或由 \(d\) 得到的 cross-sectional area \(A\)；
  • dependent variable：\(k\)；
  • control variables：wire material、number of turns、initial length 和 temperature。

只写“change diameter”不够；还要说明用 micrometer screw gauge 测量 diameter，并用 force-extension method 求 \(k\)。

3.2 Methods of data collection / 数据收集方法

完整 method 应回答：

  1. 如何改变 independent variable；
  2. 如何测量 independent variable；
  3. 如何测量 dependent variable；
  4. 如何保持 control variables constant；
  5. 如何获得 enough readings；
  6. 如何提高 repeatability 和 precision。

Example / 示例：研究 \(v\) 与 \(r\)

若题目给出：

\[ v=Y r^{-n}, \]

可以写：

  • 使用不同 radius 的 balls，改变 \(r\)；
  • 用 micrometer screw gauge 或 Vernier calipers 测量 diameter，再计算 \(r=d/2\)；
  • 用 light gate 测量 ball 通过 beam 的时间；
  • 用 ball diameter 除以 blocking time 得到 \(v\)；
  • 保持 spring compression \(x\)、spring constant \(k\) 和 ball density \(\rho\) constant；
  • 对每个 \(r\) 重复 experiment，并取 mean \(v\)。

3.3 Workable apparatus diagram / 可工作的装置图

diagram 不需要艺术化，但必须让 examiner 看出 experiment 可以真正完成。应包括：

  • apparatus 的相对位置；
  • 必要的 wires、switches、supports 和 connections；
  • measuring instrument 的位置；
  • independent/dependent quantity 的 measurement point；
  • 至少足够的 labels；
  • relevant direction、distance 或 reference point。

Example / 示例：circuit diagram

如果要测量 resistor 的 \(R\)：

  • ammeter 应与 resistor in series；
  • voltmeter 应与 resistor in parallel；
  • circuit 应有 power supply 和 switch；
  • 需要改变 \(R\) 时，应说明使用 different resistors 或 variable resistor；
  • 若要测量很短的 time interval，应使用 oscilloscope 或 data logger，不能只写 stopwatch。

3.4 Measuring instruments / 仪器选择

Instrument 必须适合被测量的 quantity 和 expected range。

Quantity Suitable instrument Example of use
Small diameter Micrometer screw gauge、Vernier calipers Wire、ball、tube 或 spring diameter
Length Metre rule、ruler、calipers Extension、distance、height
Mass Top-pan balance Mass of a ball、load 或 liquid
Force Newton meter、force sensor Force-extension relationship
Short time Light gate、oscilloscope、data logger Collision、oscillation、pulse width
Current Ammeter、digital multimeter Circuit current
Potential difference Voltmeter、digital multimeter Capacitor discharge 或 resistor p.d.
Temperature Thermometer、temperature probe Cooling、viscosity 或 heating

Example / 示例：instrument precision

若 diameter 只有约 \(2\ \mathrm{mm}\)，用 metre rule 可能产生很大的 percentage uncertainty；应选择 micrometer screw gauge 或 Vernier calipers。如果 measured change 很小，也应考虑更高 resolution 的 sensor。

3.5 Range、repeats and averages / 范围、重复和平均

规划时应明确：

  • 至少 five or six different values，具体按题目要求；
  • independent variable 覆盖 as large a range as practical；
  • 每一个点是否 repeat；
  • 是否使用 mean value；
  • 如何处理 anomalous result。

Example / 示例：stationary waves

研究 frequency \(f\) 与 tube diameter \(d\) 的关系时，可以：

  • 选择 \(d\) 覆盖较大的 range；
  • 对每个 \(d\) 找到 resonance condition；
  • 重复测量 resonant frequency；
  • 取 mean \(f\)；
  • 记录 \(d\)、\(f\) 和之后 graph 所需的 \(1/d\) 或 \(\lg d\)。

3.6 Control variables / 控制变量

控制变量必须写出实际方法，不能只列名称。

Control variable Weak statement Strong statement
Temperature Keep temperature constant Place apparatus in a water bath and monitor temperature with a thermometer
Length Keep length constant Use a fixed marker and measure from the same reference point each time
Amplitude Keep amplitude constant Use a marked release position and release without a push
Area Keep area constant Use the same plate overlap or mark the fixed area on the apparatus
Light level Keep light constant Use a dark enclosure and keep LED current constant
Number of turns Keep \(N\) constant Use the same coil and do not change its winding

Example / 示例：control variable must be operational

在 floating cylinder experiment 中，若研究 period \(T\) 随 mass \(m\) 的变化，不能只写“keep temperature constant”；应写“use the same liquid at the same room temperature and allow the cylinder to reach thermal equilibrium before timing”。

3.7 Method of analysis / 数据分析方法

Planning answer 必须说明 data 如何验证 relationship。至少应包含：

  1. 要计算哪些 derived quantities；
  2. plot 哪个 quantity against 哪个 quantity；
  3. relationship 成立时 graph 应具有什么特征；
  4. gradient 或 intercept 如何得到 required constant。

Example / 示例：power law

若：

\[ y=ax^n, \]

则：

\[ \lg y=\lg a+n\lg x. \]

因此应：

  • calculate \(\lg y\) 和 \(\lg x\)；
  • plot \(\lg y\) against \(\lg x\)；
  • relationship valid if a straight line is produced；
  • gradient gives \(n\)；
  • y-intercept gives \(\lg a\)，所以 \(a=10^{\text{intercept}}\)。

3.8 Safety and additional detail / 安全与补充细节

Safety mark 不是写一句“wear safety goggles”就一定得到。必须把 precaution 和 risk 联系起来。

Hazard Suitable precaution
Falling mass or ball Use a cushion、sand box、screen or stop to prevent injury/damage
High voltage Switch off before changing connections；avoid touching bare conductors；use insulated leads
Heated liquid or metal Use heat-resistant gloves、tongs and allow apparatus to cool
Sharp wire or spring Wear eye protection；use a safety screen；secure the spring
Glass tube or container Clamp securely and keep the apparatus away from the bench edge
Strong magnet Keep magnetic materials and electronic devices away；avoid trapping fingers
Water near electricity Keep the power supply away from the liquid and dry hands before touching equipment

Example / 示例：specific safety statement

Use a safety screen and a cushion beneath the spring because the spring or load may detach and move rapidly towards the candidate.

这比单独写 wear goggles 更具体，因为它说明了 hazard 和 precaution 的 connection。

4. Planning answer structure / Q1 答题结构

可以按以下顺序写，避免漏掉 mark scheme sections：

A. Defining the problem

  • state independent variable；
  • state dependent variable；
  • state control variables。

B. Method and apparatus

  • draw labelled diagram；
  • describe how to vary independent variable；
  • describe how to measure both variables；
  • describe how to keep controls constant；
  • state range、number of readings 和 repeats。

C. Method of analysis

  • write rearranged equation；
  • state graph axes；
  • state relationship expected if valid；
  • identify gradient/intercept and constant。

D. Additional detail and safety

  • reduce major uncertainty；
  • improve signal size；
  • include calibration or preliminary measurement；
  • explain safety precautions。

Planning sentence template / 规划答题模板

Vary ___ and measure . Keep , ___ and ___ constant. Use ___ to measure ___ and ___ to measure . Take at least readings over a range of . Repeat each reading and calculate a mean. Plot against . If the relationship is valid, the graph should be . The gradient/intercept represents ___.

5. Question 2 Data Analysis / 数据分析题

5.1 Read the equation first / 先读 equation

在计算前先确定：

  • equation 中哪个 quantity 是 \(x\)；
  • 哪个 quantity 是 \(y\)；
  • 是否需要 reciprocal、square、square root、\(\ln\) 或 \(\lg\)；
  • gradient 和 intercept 分别代表什么；
  • 哪些 quantities 的 uncertainty 需要进入 graph。

5.2 Common graph transformations / 常见图像变换

Relationship Graph Gradient / intercept
\(y=mx+c\) \(y\) against \(x\) Gradient \(m\)、intercept \(c\)
\(y=a+bx\) \(y\) against \(x\) Gradient \(b\)、intercept \(a\)
\(y=ae^{kx}\) \(\ln y\) against \(x\) Gradient \(k\)、intercept \(\ln a\)
\(y=ax^n\) \(\lg y\) against \(\lg x\) Gradient \(n\)、intercept \(\lg a\)
\(y=a/x+b\) \(y\) against \(1/x\) Gradient/intercept after rearrangement
\(y=a+bx^2\) \(y\) against \(x^2\) Gradient \(b\)、intercept \(a\)

Example / 示例：exponential relationship

若：

\[ V=V_0e^{-t/RC}, \]

取 natural logarithm：

\[ \ln V=\ln V_0-\frac{t}{RC}. \]

因此 plot \(\ln V\) against \(t\)：

  • gradient \(=-1/(RC)\)；
  • y-intercept \(=\ln V_0\)；
  • gradient 应为 negative；
  • relationship valid if points form a straight line。

5.3 Logarithms and units / 对数和单位

对数的 argument 应写成 dimensionless ratio，例如：

\[ \ln\left(\frac{V}{\mathrm{V}}\right), \qquad \lg\left(\frac{M}{10^{30}\ \mathrm{kg}}\right). \]

正确写法的重点：

  • quantity 和 unit 一起出现在 ratio 中；
  • logarithm 本身没有 unit；
  • ln 和 lg 不能混用；
  • table 中的 log values 要保持合适 decimal places；
  • 不要写 \(\ln V / \mathrm{V}\) 来代替 \(\ln(V/\mathrm{V})\)。

Example / 示例：log calculation

若 \(V=0.250\ \mathrm{V}\)，则可以计算：

\[ \ln\left(\frac{V}{\mathrm{V}}\right)=\ln(0.250)=-1.386. \]

这里 \(\ln(V/\mathrm{V})\) 是 dimensionless，log value 没有 unit。

5.4 Completing a table / 完成数据表

Paper 5 的 table 通常要求计算：

  • reciprocal quantities；
  • squares or square roots；
  • sums such as \(R_1+R_2\)；
  • averages such as \((t_1+t_2)/2\)；
  • \(\ln\) 或 \(\lg\) values；
  • transformed uncertainties。

Example / 示例：derived table

若 \(R_1=2.0\ \mathrm{k\Omega}\)、\(R_2=3.0\ \mathrm{k\Omega}\)，则 table 中可记录：

\[ R_1+R_2=5.0\ \mathrm{k\Omega}, \qquad \frac{1}{R_1+R_2}=0.200\ \mathrm{k\Omega^{-1}}. \]

不要把 \(1/(R_1+R_2)\) 错算成 \(1/R_1+1/R_2\)。

6. Graphs with uncertainty / 带 uncertainty 的 graph

6.1 Error bars

Paper 5 mark scheme 经常要求为每一个 point 画 error bars。应做到：

  • 所有 points 都有 error bars；
  • error bar 方向与 quantity 的 uncertainty 一致；
  • vertical uncertainty 用 vertical bar，horizontal uncertainty 用 horizontal bar；
  • error bar 两侧对称，除非题目明确给 asymmetric uncertainty；
  • bar 的长度按 graph scale 正确；
  • point 和 error bar 都要清晰可见。

Example / 示例：error bar

若 \(y=2.40\pm0.10\)，graph 的 vertical scale 为 \(0.20\) per large square，则 error bar 总高度应代表 \(0.20\)，即 point 上下各 \(0.10\)。

6.2 Line of best fit

Line of best fit 表示 data 的 central trend：

  • points 大致均匀分布在两侧；
  • 不应简单连接相邻 points；
  • 不要强行通过 origin，除非 equation 或题目要求；
  • 若 points 呈明显 curve，不要强行画 straight line。

6.3 Worst acceptable line

Worst acceptable line 用于估计 graph-derived quantity 的 uncertainty。它应是：

  • 能通过所有 relevant error bars 的 straight line；
  • 最 steep 或最 shallow 的 acceptable line；
  • 与 line of best fit 明确区分，例如用 dashed line 或 label；
  • 不能只通过 data points 而忽略 error bars。

Example / 示例：choosing the worst acceptable line

若所有 error bars 都允许一组正斜率 lines，则选择仍能通过全部 error bars 的最 steep line 或最 shallow line。不能选择一条只通过中间 points、但漏掉两端 error bars 的 line。

7. Gradient、intercept and graph uncertainty

7.1 Gradient

使用 line 上相距较远的 two points：

\[ m=\frac{\Delta y}{\Delta x}. \]

答案应显示 substitution，例如：

\[ m=\frac{3.20-1.10}{0.80-0.20}=3.50. \]

7.2 Absolute uncertainty in gradient

Paper 5 常用：

\[ \Delta m =|m_{\mathrm{best}}-m_{\mathrm{worst}}|. \]

某些 mark scheme 也接受以 steepest 和 shallowest lines 的 half-range 表示：

\[ \Delta m =\frac{m_{\mathrm{steepest}}-m_{\mathrm{shallowest}}}{2}. \]

以题目和 mark scheme 指定的 convention 为准。

7.3 y-intercept and its uncertainty

可以直接从 \(x=0\) read off，或使用：

\[ c=y-mx. \]

若题目要求 intercept uncertainty：

\[ \Delta c=|c_{\mathrm{best}}-c_{\mathrm{worst}}|. \]

Example / 示例：gradient uncertainty

若 \(m_{\mathrm{best}}=4.20\) 且 \(m_{\mathrm{worst}}=3.80\)，则：

\[ \Delta m=4.20-3.80=0.40. \]

最后应按题目要求写成 value、uncertainty 和 unit，例如 \(m=4.2\pm0.4\ \mathrm{s^{-1}}\)。

8. Uncertainty propagation / 不确定度传播

8.1 Basic rules

  • addition/subtraction：add absolute uncertainties；
  • multiplication/division：add fractional or percentage uncertainties；
  • powers：multiply fractional or percentage uncertainty by the power；
  • graph gradient/intercept：use best-fit and worst-acceptable lines。

8.2 Uncertainty in a logarithm

For small uncertainties：

\[ \Delta(\ln x)\approx\frac{\Delta x}{x}, \]

and：

\[ \Delta(\lg x)\approx\frac{\Delta x}{x\ln10}. \]

Example / 示例：uncertainty in \(\ln V\)

若 \(V=2.00\pm0.10\ \mathrm{V}\)，则：

\[ \Delta(\ln V)\approx\frac{0.10}{2.00}=0.05. \]

在 graph 上，\(\ln V\) 的 vertical error bar 应使用约 \(\pm0.05\)。

8.3 Uncertainty in a constant from gradient

若 \(C\) 与 gradient \(m\) 成正比：

\[ C=Km, \]

则：

\[ \frac{\Delta C}{C}=\frac{\Delta m}{m}. \]

若 \(C\) 与 \(m\)、\(c\) 都有关，则按照 equation 中的 multiplication、division 和 powers 合并 percentage uncertainties。

Example / 示例：constant from gradient

若 \(C=2.00m\)，\(m=3.0\pm0.3\)，则：

\[ C=6.0, \qquad \frac{\Delta C}{C}=\frac{0.3}{3.0}=10\%, \]

所以 \(\Delta C=0.6\)。

9. Conclusions and predictions / 结论与预测

9.1 Conclusion from a graph

结论要包含：

  • graph 是否呈现 expected straight line；
  • gradient/intercept 的 numerical value；
  • units；
  • uncertainty；
  • relationship 是否得到 support；
  • 若不支持，说明 evidence 的具体问题。

Example / 示例：conclusion

The graph is approximately a straight line, so the data support the suggested linear relationship. The gradient is \(3.5\pm0.4\ \mathrm{s\,kg^{-1}}\).

9.2 Prediction / 外推

有些 Paper 5 会要求使用 graph 或 derived equation 预测新的 quantity。步骤是：

  1. identify whether the value lies inside or outside the measured range；
  2. use the best-fit line or equation；
  3. read the graph accurately；
  4. include unit；
  5. if required，include uncertainty。

Interpolation（测量范围内）通常比 extrapolation（测量范围外）更可靠。若是 extrapolation，应在 conclusion 中说明 reliability 较低。

Example / 示例：interpolation and extrapolation

若 measured \(x\) range 是 \(2\)–\(8\ \mathrm{cm}\)，预测 \(x=5\ \mathrm{cm}\) 属于 interpolation；预测 \(x=15\ \mathrm{cm}\) 属于 extrapolation，需要谨慎说明。

10. High-frequency Paper 5 contexts / 高频情境

Paper 5 的 context 可能跨越 AS、A Level 和 unfamiliar applications，但 skill pattern 不变。

10.1 Electrical and capacitor experiments

Common contexts：capacitor discharge、resistor networks、coil、parallel plates、wind turbine generator。

常见 transformations：

  • \(\ln V\) against \(t\)；
  • \(\ln V\) against \(1/(R_1+R_2)\)；
  • \(1/V\) against plate separation \(d\)；
  • \(\lg I\) against \(\lg v\)。

Example / 示例：capacitor discharge

若 capacitor discharge equation 为 \(V=V_0e^{-t/RC}\)，Q2 通常要求计算 \(\ln V\)、画 graph、由 negative gradient 求 \(RC\)，再处理 gradient uncertainty。应检查 gradient 的 sign、error bars 和 worst acceptable line。

10.2 Waves and oscillations

Common contexts：stationary waves in strings/tubes、oscillating cylinder、power supply frequency。

重点：

  • frequency、period 和 wavelength 的转换；
  • 使用 oscilloscope 或 time-base；
  • 控制 tension、length、diameter、mass 或 amplitude；
  • 由 graph gradient 求 wave constant。

Example / 示例：stationary waves

若 \(f\) 与 tube diameter \(d\) 的关系为 \(f\propto1/d\)，应 plot \(f\) against \(1/d\)，并说明 relationship valid if a straight line is produced。若题目要求 constant，则进一步说明由 gradient 如何得到该 constant。

10.3 Mechanics and collisions

Common contexts：gliders on an air track、spring compression、inclined plane、modelling clay、floating cylinder。

重点：

  • light gates、velocity、mass 和 time；
  • release position；
  • friction 和 alignment；
  • control of distance、mass、spring compression 或 material。

Example / 示例：collision analysis

collision experiment 中，若 \(v\) 与 \(M+m\) 有 suggested equation，应先由 light gate data 得到 \(v\)，再 plot \(v\) against \(M+m\)，而不是直接 plot raw time。若 mass 有 uncertainty，需在 transformed quantity 上画相应 error bars。

10.4 Thermal and fluid experiments

Common contexts：viscous force、heating metal cylinder、cooling、liquid flow。

重点：

  • temperature measurement；
  • heat loss；
  • viscosity、flow time、surface area；
  • constant temperature 或 controlled heating。

Example / 示例：viscosity and temperature

若研究 viscosity \(\eta\) 随 temperature \(T\) 的变化，题目可能给出 \(\ln\eta\) 与 \(1/T\) 的 equation，要求完成 reciprocal temperature、log calculation 和 graph。注意 temperature 应使用 kelvin，不能直接使用摄氏温度。

10.5 Astronomy、nuclear and unfamiliar contexts

Past Paper 5 也会使用 stars、galaxies、moons、radioactive count rate 等 context。不要因为情境陌生就停止；题目会给出必要 equation 和 definitions。

Example / 示例：astronomy power law

若给出 \(L\propto M^n\)，即使 star luminosity 不是已熟悉的 laboratory experiment，也可以使用 \(\lg L\) against \(\lg M\) 的 method，gradient 仍代表 \(n\)。若 graph 的 intercept 还包含 scale factor，则需使用题目给出的 normalized quantities 处理 unit。

11. Common mark-scheme traps / 高频失分点

Planning

  • 只列 control variables，不说明如何控制；
  • diagram 缺少关键 labels 或无法实际操作；
  • 选择不适合 expected range 的 instrument；
  • 只写 take more readings，没有说明 range、repeats 或 analysis；
  • 只写 plot a graph，没有说明 axes 和 expected graph feature；
  • safety precaution 没有对应 hazard；
  • 没有说明如何得到 dependent variable；
  • 忘记 measurement of constants needed in the equation。

Data analysis

  • plot wrong transformed quantity；
  • 把 ln 和 lg 混用；
  • log argument 没有 unit ratio；
  • 只画 data points，不画 error bars；
  • error bars 不对称或长度不符合 scale；
  • worst acceptable line 没有通过 all error bars；
  • 把 best-fit gradient 当作 uncertainty；
  • gradient 写成 \(\Delta x/\Delta y\)；
  • y-intercept uncertainty 漏掉；
  • final constant 没有 unit 或 significant figures 不合理；
  • 在 equation 不要求时强行让 line pass through origin；
  • 只写“data support relationship”，没有 quantitative evidence。

12. Complete Question 2 workflow / Q2 完整流程

  1. Read the suggested equation。
  2. Identify graph \(x\) and \(y\) quantities。
  3. Check whether a reciprocal、square、log or square root is needed。
  4. Calculate all derived data with units and suitable significant figures。
  5. Calculate uncertainties in transformed quantities。
  6. Complete the table。
  7. Plot all points。
  8. Plot all error bars。
  9. Draw line of best fit。
  10. Draw and label worst acceptable line。
  11. Determine best-fit gradient and intercept。
  12. Determine gradient/intercept uncertainties。
  13. Use gradient/intercept to calculate constants。
  14. Propagate uncertainty into the constants。
  15. Write a quantitative conclusion or prediction。

Paper 3 Advanced Practical Skills / 实验技能

Complete examination framework / 完整考点框架 · Cambridge International AS & A Level Physics 9702

使用说明 / How to use this chapter

本章把 Paper 3 的考点按 skill 组织，而不是按某一个固定实验组织。考试会更换 physical context、apparatus 和 equation，但评分点通常集中在以下能力：

  • 正确操作 apparatus 并遵守 written instructions；
  • 收集足够数量、足够范围和质量良好的 data；
  • 规范记录 raw data 和 derived quantities；
  • 完成 table of results 和 graph；
  • 从 graph 得到 gradient、y-intercept 和 constants；
  • 处理 uncertainty、significant figures 和 units；
  • 写出 evidence-based conclusion；
  • 识别 limitation 并提出 realistic improvement。

核心原则 / Core principle

Paper 3 rewards reliable experimental practice. 最终数值正确只是其中一个方面；mark scheme 还会分别评价 measurement quality、data range、table conventions、graph conventions、uncertainty 和 evaluation。

1. 考试结构 / Examination structure

项目 / Feature 要求 / Requirement
Component Paper 3 Advanced Practical Skills
Duration 2 hours
Total marks 40 marks
Questions Two questions, normally 20 marks each
Question 1 Data collection、table、graph、analysis 和 conclusion
Question 2 Measurement、uncertainty、comparison、limitations 和 improvements
Examination setting Laboratory-based practical examination
Specific theory 不要求预先知道该实验的具体理论；题目会提供必要 information

Question 1：Graph-based experiment

通常需要完成：

  1. set up apparatus；
  2. collect several sets of readings；
  3. calculate derived quantities；
  4. complete a table of results；
  5. plot a graph；
  6. draw a line of best fit；
  7. determine gradient and y-intercept；
  8. use the graph to find constants or other quantities。

Question 2：Uncertainty and evaluation experiment

通常需要完成：

  1. take one or more initial measurements；
  2. estimate absolute uncertainty and percentage uncertainty；
  3. calculate a derived quantity or constant；
  4. repeat under a changed condition；
  5. compare two calculated values；
  6. decide whether a suggested relationship is supported；
  7. describe four limitations or sources of uncertainty；
  8. suggest four realistic improvements。

3. General tips / General examination habits

下面三条 general tips 与近年 mark scheme 高度一致：

3.1 Use a large spread / 使用较大的 range

如果题目给出 range，例如 0 to 20，应尽量让 measurements 分布在较大的范围内，而不是集中在中间很小的一段。这样可以：

  • improve the quality of data；
  • make the trend clearer；
  • reduce the relative effect of random uncertainty；
  • make the gradient more reliable。

3.2 Record all intermediate measurements / 记录所有中间量

如果最终量由中间步骤得到，table 中应记录完成 calculation 所需的 raw measurements 和 intermediate quantities。

例如：

\[ l=l_2-l_1 \]

那么 l_1 和 l_2 都应出现在 table 中，而不是只记录最后的 l。

3.3 Label every column / 每列写清楚 quantity 和 unit

Table heading 应包含 physical quantity、symbol 和 unit，例如：

  • \(I / \mathrm{A}\)
  • \(R / \Omega\)
  • \(t / \mathrm{s}\)
  • \(1/R / \Omega^{-1}\)

不要只写 A、s、current 或 R ohm。

Example / 示例：recording intermediate quantities

若实验需要测量一根 rod 的长度 \(l\)，其中

\[ l=l_2-l_1, \]

则 table 应记录 l₁ / cm、l₂ / cm 和 l / cm。只记录最后的 \(l\) 会使 calculation 过程无法检查，也可能失去 data-recording mark。

4. Manipulation、measurement and observation

4.1 Setting up apparatus / 组装和调整

Candidates should be able to：

  • follow written instructions and apparatus diagrams；
  • set up a circuit without supervisor assistance；
  • connect an ammeter in series and a voltmeter in parallel；
  • use a switch safely and open the circuit when readings are not being taken；
  • position clamps、stands、pulleys、springs、rulers 和 masses correctly；
  • make a system horizontal or vertical when required；
  • align moving objects、light sources、sensors、rulers 和 strings；
  • adjust the apparatus gradually until the required condition is reached；
  • avoid disturbing the apparatus during a reading。

4.2 Common measuring instruments / 常见仪器

Quantity Apparatus Key technique
Length / distance Millimetre ruler、metre rule Eye-level reading、avoid parallax
Small diameter / thickness Vernier calipers、micrometer screw gauge Measure at suitable positions；do not over-tighten
Mass Top-pan balance Zero or tare the balance；wait for a stable display
Force Newton meter、masses and hanger Check zero；read at eye level；keep force in the required direction
Time Stopwatch、digital timer Time several cycles or repeated events
Current Ammeter、digital multimeter Connect in series；choose a suitable range
Potential difference Voltmeter、digital multimeter Connect in parallel；choose a suitable range
Temperature Thermometer、temperature probe Keep the bulb or probe at the correct position
Angle Protractor Align baseline and avoid parallax

4.3 Micrometer screw gauge / 螺旋测微器

基本操作：

  1. Place the object between the anvil and spindle；
  2. rotate the thimble until the object is held firmly but not compressed；
  3. read the main scale；
  4. read the rotating or thimble scale；
  5. add the two scale readings；
  6. check zero error before using the instrument。

适合测量 small thickness 或 diameter。若单个物体太薄，可以测量一叠 objects，再除以数量，但必须说明这种方法的 logic。

Example / 示例：micrometer screw gauge

假设 main scale 读数为 \(5.50\ \mathrm{mm}\)，thimble scale 读数为 \(0.24\ \mathrm{mm}\)，则：

\[ d=5.50+0.24=5.74\ \mathrm{mm}. \]

实际考试还要检查 zero error，并按照题目要求记录合适的 significant figures。

4.4 Vernier scale / 游标卡尺

基本操作：

  1. place the object between the jaws；
  2. move the sliding scale until it just touches the object；
  3. read the main scale；
  4. identify the vernier division that aligns with a main-scale division；
  5. combine the main-scale reading and vernier reading；
  6. check for zero error。

Example / 示例：Vernier calipers

若 main scale 为 \(12.0\ \mathrm{mm}\)，而与 main-scale mark 对齐的 vernier division 对应 \(0.6\ \mathrm{mm}\)，则直径为：

\[ d=12.0+0.6=12.6\ \mathrm{mm}. \]

不要把 vernier reading 单独当作最终读数。

4.5 Timing oscillations / 振动计时

对于 spring、pendulum、chain 或 wooden strip：

  1. displace the system through a small and repeatable amplitude；
  2. release without an additional push；
  3. count \(n\) complete oscillations；
  4. measure total time \(t\)；
  5. calculate

\[ T=\frac{t}{n}; \]

  1. repeat the timing where appropriate；
  2. keep the amplitude and initial condition consistent。

Timing many oscillations reduces the relative effect of reaction time。

Example / 示例：period measurement

若 \(n=10\) 个 oscillations 的总时间为 \(t=12.6\ \mathrm{s}\)，则：

\[ T=\frac{12.6}{10}=1.26\ \mathrm{s}. \]

相比只计时一个周期，计时十个周期会减小 start/stop reaction time 对最终 \(T\) 的相对影响。

5. Data collection and data quality

高分 data collection 通常需要：

  • readings physically reasonable；
  • enough distinct values of the independent variable；
  • a large usable range；
  • correct trend；
  • repeated readings where random variation is important；
  • consistent measurement technique；
  • sufficient precision for the instrument；
  • no unnecessary supervisor assistance。
警告Narrow range is a common loss of marks

Six readings in a narrow interval do not automatically receive full credit. Mark schemes often specify a minimum range for mass、length、resistance 或 other independent variables。

Example / 示例：data range

研究 mass \(m\) 对 period \(T\) 的影响时，六组 \(m=280,285,290,295,300,305\ \mathrm{g}\) 的 readings range 太窄；若 apparatus 允许，更好的设计是覆盖例如 \(100\)–\(500\ \mathrm{g}\)，并保持其他 variables constant。

6. Table of results / 数据表

6.1 Required contents

Table should include：

  • every raw measurement；
  • every required derived quantity；
  • intermediate quantities used in the calculation；
  • all quantities needed for the graph；
  • quantity/unit headings；
  • consistent decimal places；
  • justified significant figures。

6.2 Accepted headings

Quantity Accepted heading
Current in amperes \(I / \mathrm{A}\)
Resistance in ohms \(R / \Omega\)
Time in seconds \(t / \mathrm{s}\)
Reciprocal resistance \(1/R / \Omega^{-1}\)
Squared period \(T^2 / \mathrm{s^2}\)
Square root of period \(\sqrt{T} / \mathrm{s^{1/2}}\)
Temperature change \(\Delta\theta / \mathrm{K}\) or \(\Delta\theta / ^\circ\mathrm{C}\), as appropriate

6.3 Raw data consistency

  • 同一 column 的 raw readings 保持相同 decimal places。
  • Millimetre ruler 的 reading 不应写成 whole centimetres。
  • Stopwatch 若读到 0.1 s，整列都要保持 0.1 s；不能混用 0.01 s。
  • Calculated quantity 的 precision 不能超过 raw data 所支持的 precision。

Example / 示例：table of results

\(m / \mathrm{g}\) \(t / \mathrm{s}\) \(T=t/n / \mathrm{s}\)
100 12.4 1.24
200 15.8 1.58

这里 raw time 统一记录到 \(0.1\ \mathrm{s}\)，而 calculated \(T\) 保留到 \(0.01\ \mathrm{s}\)，因为 \(T\) 是由 \(t/n\) 得到的 derived quantity。

7. Graph skills / 作图技能

7.1 Axes and scale

作图前先判断 equation 需要的 variables。然后：

  • 写正确的 \(x\)-axis 和 \(y\)-axis quantities；
  • 写 units；
  • 选择 simple scale，例如 1、2 或 5 units per large square；
  • 让 points 在两个方向都占 graph grid 的至少一半；
  • 必要时使用 false origin；
  • scale labels 保持规律；
  • 避免 awkward scale，例如 3 units per large square。

7.2 Plotting points

  • Plot every observation in the table。
  • Use a small cross or fine encircled dot。
  • Accuracy should be better than half a small square where possible。
  • Do not join points dot-to-dot。
  • If a point is anomalous，circle or label it clearly。

7.3 Line of best fit

合格的 line of best fit 应：

  • follow the overall trend；
  • have an approximately even distribution of points on both sides；
  • be straight for a linear relationship；
  • be thin、continuous and not kinked；
  • cover the full data range；
  • not be forced through every point。

7.4 Gradient and y-intercept

对于：

\[ y=mx+c \]

其中 \(m\) 是 gradient，\(c\) 是 y-intercept。

使用 line 上两个相距较远的 points：

\[ m=\frac{\Delta y}{\Delta x}. \]

注意：

  • 必须是 \(\Delta y/\Delta x\)，不能倒置；
  • 两点间距最好超过 drawn line 长度的一半；
  • read-off 应准确到 half a small square；
  • gradient 和 intercept 都要有正确 units；
  • false origin 下不能把图纸边界误认为 \(x=0\)。

如果 intercept 不能直接读出，可使用：

\[ c=y-mx. \]

Example / 示例：gradient and intercept

若 line of best fit 上取两点 \((x_1,y_1)=(0.20,1.10)\) 和 \((x_2,y_2)=(0.80,2.90)\)，则：

\[ m=\frac{2.90-1.10}{0.80-0.20}=3.0. \]

再用 \(y=mx+c\) 代入 \((0.20,1.10)\)：

\[ c=1.10-3.0\times0.20=0.50. \]

实际答案必须根据 graph 的 units 写出 gradient 和 intercept 的单位。

8. Data analysis and physical relationships

8.1 Linearisation / 线性化

许多 Paper 3 equation 会要求先计算 derived quantity，再画 linear graph。

Given relationship Graph Interpretation
\(y=mx+c\) \(y\) against \(x\) Gradient \(m\)、intercept \(c\)
\(y=a+bx\) \(y\) against \(x\) Gradient \(b\)、intercept \(a\)
\(y=a/x+b\) \(y\) against \(1/x\) Gradient/intercept from rearranged equation
\(y=ax^2+b\) \(y\) against \(x^2\) Gradient \(a\)、intercept \(b\)
\(y=a\sqrt{x}+b\) \(y\) against \(\sqrt{x}\) Gradient \(a\)、intercept \(b\)
\(y=a/x^2+b\) \(y\) against \(1/x^2\) Gradient/intercept from rearranged equation

8.2 Analysis routine

  1. Write the suggested equation。
  2. Rearrange into \(y=mx+c\) form。
  3. Identify graph axes。
  4. Identify the physical meaning of gradient。
  5. Identify the physical meaning of intercept。
  6. Substitute measured gradient/intercept。
  7. Include units。
  8. Round only at the end。

Example / 示例：choosing a graph

若题目给出

\[ T^2=am+b, \]

应计算 \(T^2\)，画 \(T^2\) against \(m\)。此时 gradient 是 \(a\)，y-intercept 是 \(b\)。不能直接画 \(T\) against \(m\) 后再使用同一个 interpretation。

8.3 Conclusion from a graph

Conclusion should state：

  • observed relationship；
  • value of the relevant constant；
  • unit；
  • whether the data support the suggested relationship；
  • quantitative evidence used for the decision。

9. Errors and uncertainty / Errors and uncertainty

9.1 Systematic error vs random error

Term Meaning Treatment
Systematic error readings are shifted consistently too high or too low Cannot be removed by repeating or averaging；check zero、calibration and method
Random error readings fluctuate unpredictably around a mean Can be reduced by repeat readings and averaging
Accuracy agreement with the true or accepted value Affected strongly by systematic error
Precision agreement between repeated readings Affected strongly by random scatter

一个 result 可以 precise but not accurate：重复值很接近，但整体受到 systematic error 的影响。

Example / 示例：systematic vs random error

若 voltmeter 在 zero input 时仍读出 \(+0.20\ \mathrm{V}\)，这是 zero error，会让 readings 整体偏高，属于 systematic error；重复测量和 averaging 不能消除它。

若 stopwatch 的 readings 为 \(12.4\)、\(12.8\)、\(12.5\ \mathrm{s}\)，这种 scatter 主要表现为 random error，可以通过 timing more oscillations 和 repeated readings 减小影响。

9.2 Absolute、fractional and percentage uncertainty

若：

\[ x=(2.0\pm0.1)\ \mathrm{mm} \]

则：

\[ \Delta x=\pm0.1\ \mathrm{mm} \]

\[ \text{fractional uncertainty}=\frac{\Delta x}{x} \]

\[ \text{percentage uncertainty}=\frac{\Delta x}{x}\times100\%. \]

9.3 Typical instrument uncertainty

常见的 practical estimates 包括：

Instrument Typical uncertainty used in practice
Ruler Approximately \(0.1\ \mathrm{cm}\), depending on the scale and reading method
Protractor Approximately \(2^\circ\), depending on the apparatus
Stopwatch Half the range of repeated readings, where appropriate
Digital meter Based on display resolution and stability

考试时应以题目、apparatus 和 mark scheme 的 context 为准，不要机械套用一个固定 uncertainty。

Example / 示例：percentage uncertainty

若 ruler measurement 为 \(L=25.0\pm0.5\ \mathrm{cm}\)，则：

\[ \text{percentage uncertainty}=\frac{0.5}{25.0}\times100\%=2.0\%. \]

9.4 Repeated readings

若 repeated readings 合适：

\[ \text{absolute uncertainty} \approx \frac{\text{maximum}-\text{minimum}}{2}. \]

即使 repeated readings 相同，uncertainty 也不能随意写成 zero，因为 instrument resolution 和 technique 仍然存在。

Example / 示例：half-range uncertainty

若 repeated readings 为 \(1.24\)、\(1.30\)、\(1.28\ \mathrm{s}\)，则：

\[ \Delta t=\frac{1.30-1.24}{2}=0.03\ \mathrm{s}. \]

9.5 Combining uncertainties

在本课程常见的简单规则中：

  • added/subtracted quantities：add absolute uncertainties；
  • multiplied/divided quantities：add percentage or fractional uncertainties；
  • powered quantities：percentage uncertainty multiplied by the power。

例如：

\[ p=2x+y \quad\Rightarrow\quad \Delta p=2\Delta x+\Delta y \]

而如果：

\[ r=2xy^3 \]

则 fractional 或 percentage uncertainty 应按各 quantity 的 power 处理。

Example / 示例：combining uncertainty

若 \(p=x+y\)，且 \(x=4.0\pm0.1\) 和 \(y=6.0\pm0.2\)，则：

\[ p=10.0, \qquad \Delta p=0.1+0.2=0.3. \]

因此可写为 \(p=10.0\pm0.3\)，具体 rounding 仍应遵循题目要求。

10. Testing a suggested relationship

Q2 常要求在两个不同 conditions 下求 \(k_1\) 和 \(k_2\)。建议按以下顺序：

  1. calculate \(k_1\)；
  2. calculate \(k_2\)；
  3. calculate percentage difference；
  4. compare with given uncertainty or tolerance；
  5. write a consistent conclusion。

常用形式：

\[ \text{percentage difference} = \frac{|k_1-k_2|}{\text{mean of }k_1\text{ and }k_2} \times100\%. \]

Model conclusion

The percentage difference between the two values of \(k\) is %. This is smaller/larger than the stated uncertainty of %, so the results do/do not support the suggested relationship.

不要只写 the values are close 或 the experiment is accurate；必须进行 numerical comparison。

Example / 示例：testing a relationship

若 \(k_1=2.10\)、\(k_2=2.16\)，则 percentage difference 约为 \(2.8\%\)。若题目给出的 uncertainty 为 \(5\%\)，因为 \(2.8\%<5\%\)，可以说 data support the suggested relationship。

11. Evaluation / Limitations and improvements

11.1 Four-mark limitation strategy

每一个有效 point 通常给1 mark，最多4 marks。建议采用：

Measured quantity + specific difficulty + effect on uncertainty or reliability

例如：

It is difficult to measure \(h\) because the ruler moves when it is touched, giving a large uncertainty in \(h\).

对应的 improvement 可以写成：

Clamp the ruler in a stand so that it remains vertical and does not move during the reading.

11.2 Common limitation categories

Reading and parallax

  • scale cannot be viewed perpendicularly；
  • pointer、liquid level 或 object edge is difficult to identify；
  • ruler moves during the reading；
  • meniscus 或 refraction makes the surface unclear。

Timing

  • reaction time affects start/stop；
  • difficult to judge when an object reaches a marker；
  • period changes because amplitude decreases；
  • total timing interval is too short。

Alignment and geometry

  • object is not circular、straight or uniform；
  • rulers are not parallel；
  • string、rod or mass is not in the required plane；
  • system is not horizontal or vertical；
  • cylinder、tube or board is not aligned。

Movement and stability

  • pointer oscillates；
  • support、clamp or stand moves；
  • object slips、rolls sideways or hits apparatus；
  • spring or string does not remain in the same position。

Electrical measurements

  • crocodile clips make poor contact；
  • wire short-circuits；
  • resistance changes due to heating；
  • ambient light affects an LDR；
  • current or voltage reading fluctuates。

Thermal and fluid effects

  • heat is lost through the sides or bottom；
  • thermometer bulb is not fully immersed；
  • temperature continues changing after the switch is opened；
  • temperature change is small compared with thermometer resolution；
  • refraction or curved container makes depth difficult to measure。

Insufficient data

  • two readings are not enough to draw a valid conclusion；
  • too few values of the independent variable are available；
  • no reliable trend or graph can be established。

11.3 Specific Error → Improvement bank

下面整理了可以迁移到 Paper 3 的 Error → Improvement patterns：

Error / limitation Specific improvement
Parallax when reading a ruler Read at eye level；use a mirror scale、shadow projection or a fixed pointer
Difficult to locate the centre of a ball Mark the centre with a fiducial marker
Fast-moving object makes the end point difficult to judge Use a sensor or record with a camera frame by frame
Water surface is unclear because of meniscus/refraction Use coloured liquid or a transparent pointer arrangement
Labels get wet or ink runs Use waterproof labels or waterproof ink
Bounce is inconsistent Use a flat surface and fixed release position
Oscillation time is too short Time more oscillations；use video or a motion sensor
Object does not swing freely Reduce friction；make the pivot hole larger or use a suitable bush
Oscillation dies out quickly Reduce air movement；use a heavier or more suitable object
Retort stand moves Add weights、clamp or fix the stand to the bench
Resistance/current fluctuates Clean contacts and secure the wires
Voltmeter resolution is insufficient Use a more sensitive or digital voltmeter
Force rises suddenly Use a force sensor with a data logger
Weights move off the intended path Fix the loop or hanger with tape/glue；use a guide
Masses hit each other in a pulley experiment Use a larger pulley or improve alignment
Friction at the pulley Lubricate the pulley or use a lower-friction arrangement
Heat loss through sides/bottom Lag or insulate the container；use a polystyrene cup
Thermometer bulb not fully immersed Use a larger volume or a temperature probe/thermocouple
Resistor continues heating after switch-off Wait for a stable maximum/minimum temperature before reading
Object has not reached terminal velocity Measure time over several markers or a longer distance
External light affects an LDR Conduct the experiment in a dark room or use an enclosure
Tube length changes when material is added Make pre-slots or fixed marks on the tube
Cylinders are not aligned Align them on a ruler or bench；use tape/clamps
Ruler slips on a support Glue or tape the support to a fixed block
Newton meter is not parallel to the ruler Use a long string、pulley and weights；ensure the force is parallel
Circular object has non-uniform diameter Use Vernier calipers or micrometer screw gauge at several positions
Protractor wobbles Clamp it or use a fixed protractor with a horizontal reference line
Two readings are insufficient Take several readings over a range and plot a graph，or calculate more values of the constant
警告Avoid vague improvements

Repeat the experiment、use a more accurate instrument 或 reduce errors alone is usually too vague. The improvement must state what changes, how it is implemented and which limitation it addresses。

12. High-frequency experimental contexts

12.1 Oscillations

Common variables：\(T\)、\(T^2\)、\(\sqrt{T}\)、mass、length、amplitude。

Key skills：

  • time many oscillations；
  • maintain small and consistent amplitude；
  • avoid pushing the object when releasing；
  • control pivot、friction、air movement and support stability；
  • calculate period and linearise the relationship。

Example / 示例：oscillation graph

改变 suspended mass \(m\)，测量 \(T\)，计算 \(T^2\)，画 \(T^2\) against \(m\)，再由 gradient 求 spring constant 或其他 given constant。每一个 mass 应重复 timing，并保持 amplitude 和 release method constant。

12.2 Equilibrium、moments and deformation

Common variables：mass、force、distance、angle、extension、deflection。

Key skills：

  • establish horizontal or vertical alignment；
  • identify the correct pivot or reference point；
  • measure small changes with suitable precision；
  • prevent the ruler、rod、support or mass from moving；
  • use moments、force relationships or a graph to find a constant。

Example / 示例：equilibrium and moments

在 metre rule 上改变 hanging mass，调节 position 直到 rule horizontal，再记录 distance 和 mass，用 principle of moments 检验 suggested relationship。应使用 set square 或 spirit level 判断 horizontal，并从同一个 pivot/reference point 测量 distance。

12.3 Electrical circuits

Common variables：\(V\)、\(I\)、\(R\)、distance、light level、wire length。

Key skills：

  • correct series/parallel connections；
  • avoid short circuits；
  • secure crocodile clips；
  • control heating and ambient light；
  • use reciprocal quantities when required；
  • include correct electrical units。

Example / 示例：electrical measurement

改变 LDR 与 LED 的 distance \(d\)，记录 resistance \(R\)，控制 ambient light，并用 graph 检查 \(R\) 与 \(d\) 的关系。应固定 LED current、保持 LDR 和 LED 对齐，并检查 crocodile clips 的 contact。

12.4 Thermal and fluid experiments

Common variables：temperature、temperature change、volume、depth、mass、flow time。

Key skills：

  • reduce heat loss；
  • position the thermometer correctly；
  • read temperature and time consistently；
  • measure liquid depth and volume without parallax or refraction problems；
  • recognise large percentage uncertainty when the change is small。

Example / 示例：cooling experiment

测量 hot water 的 cooling rate 时，使用 polystyrene cup、stirrer 和 fixed time interval，减少 heat loss 和 temperature-reading uncertainty。thermometer bulb 应完全浸入，并在每个 fixed time 读取 temperature。

12.5 Optics and geometry

Common variables：angle、distance、height、sine/cosine/tangent quantities。

Key skills：

  • align normal、ruler and protractor；
  • prevent protractor movement；
  • read angles consistently；
  • justify significant figures in trigonometric quantities。

Example / 示例：angle and significant figures

测量 angle \(\theta\) 后计算 \(\sin\theta\) 时，raw angle 只读到 nearest degree，因此不能给 \(\sin\theta\) 过多 significant figures。protractor 应固定并从 eye level 读取，以减少 parallax。

13. Complete Question 1 workflow

Before taking readings

  • Read the whole question。
  • Identify independent and dependent variables。
  • Check the apparatus diagram。
  • Note the required range and number of readings。
  • Prepare the table headings。
  • Decide which readings need repeats。

During data collection

  • Set up carefully and ask for help only if genuinely necessary。
  • Record raw readings immediately。
  • Use consistent units and precision。
  • Repeat timing or unstable measurements。
  • Check that the trend is physically sensible。
  • Spread the independent variable across the largest useful range。

During data processing

  • Calculate all required derived quantities。
  • Check significant figures and units。
  • Plot every data point。
  • Use sensible graph scales。
  • Draw a balanced line of best fit。
  • Use widely separated points for gradient。
  • Determine intercept correctly。
  • Convert gradient/intercept into the required constants。

14. Complete Question 2 workflow

  1. Take the first required measurement。
  2. Record the raw value with suitable precision。
  3. Estimate absolute uncertainty。
  4. Calculate percentage uncertainty。
  5. Calculate the derived quantity or constant。
  6. Justify significant figures if asked。
  7. Change the specified variable and repeat。
  8. Calculate the second value of the constant。
  9. Calculate percentage difference。
  10. Compare with the given uncertainty or tolerance。
  11. Write a quantitative conclusion。
  12. Give four specific limitations。
  13. Give four realistic improvements linked to those limitations。

15. Common mark-scheme traps

Data collection

  • Six readings with an inadequate range may not receive full data-quality credit。
  • Repeating one value without changing the independent variable does not create a useful range。
  • Supervisor assistance can prevent full credit for successful data collection。

Tables

  • A unit by itself is not a complete heading。
  • Mixed decimal places in one raw-data column can lose the consistency mark。
  • Calculated values with unjustified precision can lose the significant-figures mark。

Graphs

  • A graph using only a small corner of the grid is weak even if the points are correct。
  • A best-fit line is not a point-to-point join。
  • The gradient is \(\Delta y/\Delta x\)，not \(\Delta x/\Delta y\)。
  • A gradient triangle that is too small gives an unreliable result。

Uncertainty and evaluation

  • The result is inaccurate is not a specific limitation。
  • Parallax error without naming the affected measurement is too vague。
  • Repeat the experiment alone is usually insufficient as an improvement。
  • The final conclusion must be based on a numerical comparison。
